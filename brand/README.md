# Bookrail brand assets

The mark is six rounded cells in three columns and two rows, the left column narrower, one cell
in cobalt. The grid is the time grid of the product; the cobalt cell is the slot that has been
taken.

The files in this directory are the ones the site and the documentation build from, and they
are the ones to use:

- `bookrail-mark.svg`: ink `#111111` and cobalt `#2857f0`, for light grounds.
- `bookrail-mark-on-dark.svg`: white and cobalt, for dark grounds.
- `bookrail-mark-mono.svg`: one colour (`currentColor`), for inline use and monochrome contexts.
- `favicon.svg`: the mark, as the site favicon.
- `png/bookrail-icon-180.png`: the touch icon.
- `png/bookrail-social-1200x630.png`: the social card, rendered from the same SVG.

Wordmark: "Bookrail" set in Bricolage Grotesque 600, letter-spacing -0.035em, ink on light,
white on dark. Clear space around the mark: half its width. Never stretch, never recolour
beyond the palette above, never add a gradient or a shadow.

Minimum sizes: 16 px as a favicon, where the cells still read as a grid, and 20 px next to the
wordmark.
